title: Five words this project uses precisely
date: 2026-06-07
tags: [agents]
---

The design set uses a handful of words in a narrower sense than usual.

1. **Primitive** — one of the thirteen block types the vocabulary defines.
2. **Twin** — the markdown file served beside every HTML page.
3. **Look** — a theme plus one of its named variations.
4. **Budget** — a number in `snypd.yaml` that fails the build when exceeded.
5. **Desk** — the page the preview server serves for a person.

They are numbered so they can be referred to; they are not a procedure.
