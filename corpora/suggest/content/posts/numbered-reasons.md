---
title: Three reasons the only interface is MCP
date: 2026-06-10
tags: [agents]
---

People ask why there is no admin page, and the answer has three parts.

1. The author is already in a harness that speaks MCP, so a second interface is a second place to be.
2. Every write through one path is a write that can be linted, versioned and reviewed the same way.
3. A dashboard is a product surface that has to be designed, tested and kept accessible forever.

The third reason is the one that decided it.
