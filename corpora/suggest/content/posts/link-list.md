The design set draws on a handful of outside documents, and these are the ones that mattered most.

- [The MCP specification](https://example.com/mcp) — the protocol, and the reason there is no other interface
- [CommonMark](https://example.com/commonmark) — what a markdown file means, including the parts that hurt
- [Core Web Vitals](https://example.com/cwv) — the three numbers a page is judged on, and why CLS is the honest one
- [IndexNow](https://example.com/indexnow) — the one protocol four search engines agree on

None of these is required reading. Each explains one decision.
