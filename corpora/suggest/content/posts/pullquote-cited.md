title: The sentence the whole design turns on
date: 2026-05-02

Every argument in the design set descends from one line, and it is not ours.

> "The tool that writes the site is the tool you are already talking to." — from the first design review

Everything else follows: no admin, no dashboard, no editor, because each of those is a second tool. The MCP server is the interface, and the interface is the harness the author already has open.
