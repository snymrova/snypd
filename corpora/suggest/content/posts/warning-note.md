Every number on the bench page comes from the same box, and that box is a four-core laptop.

> Warning: none of these numbers are comparable to a cloud runner. They are useful against each other and against themselves over time, and for nothing else.

We publish the load average beside every run for exactly this reason. A build that reads 700 ms at load 10 and 500 ms at load 4 has not regressed.
